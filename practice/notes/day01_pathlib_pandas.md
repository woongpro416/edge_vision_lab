# Day 01 - pathlib와 pandas 기초

## 배운 내용

- 문자열 경로와 `Path` 객체는 다르다.
- 문자열 경로를 `Path` 객체로 변환하면 파일 시스템 관련 기능을 명확하게 사용할 수 있다.
- `Path` 객체를 사용하면 폴더 존재 여부 확인, 폴더 내부 파일 순회, 확장자 확인, 파일 크기 조회 등을 일관된 방식으로 처리할 수 있다.
- 파일 하나의 정보는 `dict`로 표현할 수 있고, 여러 파일 정보는 `list[dict]` 형태로 모을 수 있다.
- `pandas.DataFrame`은 `list[dict]` 형태의 데이터를 표 형태로 변환해준다.
- `print()`로 결과를 눈으로 확인하는 것과 `assert`로 기대 조건을 코드가 직접 검사하는 것은 다르다.

## 실습 내용

- 이미지 폴더 안의 파일 목록을 `pathlib.Path`로 순회했다.
- `.jpg`, `.jpeg`, `.png` 확장자를 가진 이미지 파일만 필터링했다.
- 각 이미지 파일의 이름, 경로, 확장자, 크기 정보를 `dict`로 정리했다.
- 여러 파일 정보를 `list[dict]`로 모은 뒤 `pandas.DataFrame`으로 변환했다.
- 빈 폴더일 때 반복문 안에서 만든 변수가 존재하지 않아 발생하는 문제를 확인하고 수정했다.
- 간단한 `assert`를 사용해 기대한 조건이 맞는지 확인했다.

## 핵심 정리

```text
str 경로와 Path 객체는 다르다.

Path 객체는 파일과 폴더를 다룰 수 있는 기능을 제공한다.

dict 1개 = 파일 1개의 정보
list[dict] = 여러 파일의 정보
DataFrame = 여러 파일 정보를 표 형태로 정리한 결과

for문 안에서 만든 변수는 반복문이 한 번도 실행되지 않으면 생성되지 않을 수 있다.

print는 사람이 눈으로 확인하는 방식이고,
assert는 코드가 기대 조건을 직접 검사하는 방식이다.
```

### 추가 학습 정리

오늘은 테스트 코드를 보충하면서 빈 폴더, 이미지가 아닌 파일, 대소문자 확장자 상황을 확인했다.

빈 폴더에서는 `rows`가 빈 리스트로 유지되기 때문에 `DataFrame`의 row 수가 0이 된다.  
반면 `for`문 안에서 처음 만들어지는 `item` 같은 변수는 반복문이 한 번도 실행되지 않으면 존재하지 않을 수 있다.

`.txt` 파일이 섞여 있어도 결과에는 포함되지 않아야 하며, `.jpg`, `.jpeg`, `.png` 확장자만 허용하도록 검사했다.  
또한 `.JPG`, `.JPEG`, `.PNG`처럼 대문자가 섞인 확장자는 `.lower()`로 소문자 변환 후 저장했다.

반복해서 사용하는 고정값은 상수로 분리했다.

```python
IMAGE_EXTENSIONS = {".jpg", ".jpeg", ".png"}
COLUMNS = ["file_name", "extension", "file_path", "size_bytes"]
```

IMAGE_EXTENSIONS는 허용할 이미지 확장자 규칙이고, COLUMNS는 DataFrame이 유지해야 할 컬럼 구조이다.
상수로 분리하면 같은 값을 여러 곳에 반복해서 쓰지 않아도 되고, 나중에 수정할 때 한 곳만 바꾸면 된다.
